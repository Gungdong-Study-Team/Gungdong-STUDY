# 프로그래머스 SQL 회고록 - 카테고리 별 상품 개수 구하기

## 문제유형

| 항목 | 내용 |
|---|---|
| 문제 플랫폼 | 프로그래머스 |
| 문제명 | 카테고리 별 상품 개수 구하기 |
| 유형 | SQL |
| 분류 | GROUP BY |
| 핵심 개념 | 문자열 함수, 그룹화, 집계 |
| 사용 함수 | `LEFT()`, `COUNT()` |
| 주요 포인트 | 상품 코드의 앞 2글자를 기준으로 카테고리를 구분하고, 카테고리별 상품 개수를 집계하는 문제 |

---

## 내 풀이 방법
상품 코드 별로 개수를 구하기 위해 GROUP BY를 사용하였으며 앞의 2글자를 뽑기 위해 LEFT 함수를 사용하였다.


---

## 회고
SUBSTRING 방식으로도 할 수 있지만 더 좋은 함수가 없을까 싶다가 LEFT 라는 함수가 있길래 써봤다.
