# 풀이방법
물고기 타입 별 가장 긴 물고기 길이 쿼리문
JOIN, 서브쿼리, ORDER BY 오름차순

## 코드
```
SELECT A.ID, B.FISH_NAME, A.LENGTH
FROM FISH_INFO A, FISH_NAME_INFO B
WHERE A.FISH_TYPE = B.FISH_TYPE
  AND A.LENGTH = (
      SELECT MAX(C.LENGTH)
      FROM FISH_INFO C
      WHERE C.FISH_TYPE = A.FISH_TYPE
  )
ORDER BY A.ID ASC;
```

## 회고
개인적으로 아직 서브쿼리가 익숙하지 않은듯</br>
그래도 join은 보다 쉽게 한듯..??

## AI 코드
```
SELECT A.ID,
       B.FISH_NAME,
       A.LENGTH
FROM FISH_INFO A
JOIN FISH_NAME_INFO B
    ON A.FISH_TYPE = B.FISH_TYPE
JOIN (
    SELECT FISH_TYPE, MAX(LENGTH) AS MAX_LENGTH
    FROM FISH_INFO
    GROUP BY FISH_TYPE
) C
    ON A.FISH_TYPE = C.FISH_TYPE
   AND A.LENGTH = C.MAX_LENGTH
ORDER BY A.ID;
```
