## 📌 스터디 규칙

### 🎯 주간 진행 목표

매주 **총 3문제**를 필수로 풀이합니다.

* **문제 유형:** 알고리즘 또는 SQL 중 자유롭게 선택
* **문제 난이도:** Level 0, 1, 2 등 제한 없이 자유롭게 선택
* 유형과 난이도에 관계없이 총 3문제를 풀이하면 주간 목표를 달성한 것으로 인정합니다.

### 📝 주간 문제 풀이 면제

해당 주에 다음 일정이 있는 경우 주간 문제 풀이를 면제받을 수 있습니다.

* 취업 면접
* 어학시험
* 자격증 시험
* 그 밖의 이에 준하는 시험

> 단, **코딩테스트는 면제 사유에 포함되지 않습니다.**

### 🚨 패널티 (Penalty)

> **"할당량 미달성 시 커피 쏘기! ☕💸"**

정해진 기한 내에 주간 목표인 3문제를 모두 풀지 못한 멤버는 다음 주 중 스터디원들에게 시원한 커피를 사야 합니다.

단, 위의 면제 조건에 해당하는 주에는 패널티가 적용되지 않습니다.
